About me

Mechanical engineer turned robotics software engineer. I work across the full stack, from CAD and URDF up to drivers, fusion and deployed ML.

I'm a Robotics Software Engineer with an M.Sc. in Mechatronics from Hochschule Ravensburg-Weingarten. I write ROS2 software in C++ and Python for perception, sensor fusion, calibration and robot manipulation.
