# sourav0607.github.io (source)

React + TypeScript + Tailwind CSS + Framer Motion + Lucide, built with Vite.

- Content lives in `src/data.ts`; sections in `src/sections/`, shared pieces in `src/components/`.
- `npm install` then `npm run dev` to work locally, `npm run build` to produce `dist/`.
- Deploy: copy `dist/` contents to the `main` branch root (GitHub Pages serves `main`).
